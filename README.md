# Derivative formulas of the MAP loss function are derived for each example
## Example 1
$$\frac{\partial J}{\partial \theta}=-\frac{k+\alpha -1}{\theta}+\frac{n-k+\beta -1}{1-\theta}$$
## Example 2
$$\frac{\partial J}{\partial \lambda}=-\frac{N+\alpha -1}{\lambda}+(\sum_{i=1}^N x_i + \beta)$$
## Example 3
$$\nabla_w J=X^T(Xw-y)+\lambda w$$
